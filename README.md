# Supermarket Simulator 3D

A mobile-friendly 3D supermarket prototype built with Three.js.

## Run locally
```bash
npm install
npm run dev
``

## Controls
- Mobile: on-screen joystick; RESTOCK and CHECKOUT buttons.
- Desktop: WASD or arrow keys; Space to interact.

## Current features
- 3D supermarket interior, product shelves, checkout and shoppers
- Mobile touch controls and desktop keyboard controls
- Simple stocking, checkout and cash counter

## App packaging
This repository currently contains the web game source, not a signed APK or IPA. Android packaging can be added with Capacitor and built with Android tooling. A signed iOS IPA requires macOS/Xcode and valid Apple signing.
